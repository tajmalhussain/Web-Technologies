1. Internet Overview

The Internet is a global network of interconnected computer networks. It allows computers and devices to communicate using standard protocols such as TCP/IP.

2. Fundamental Computer Network Concepts

A computer network connects devices so that they can exchange data and share resources.

IP AddressTCP/IP DNSHTTP/HTTPSRouter
  • IP Address: Identifies a device on a network.
  • Protocol: A set of communication rules.
  • DNS: Converts domain names into IP addresses.
  • HTTP/HTTPS: Protocols used to transfer web resources.
  • Router: Forwards packets between networks.

3. URL and Its Structure

A URL (Uniform Resource Locator) identifies the location of a resource on the web.

https://www.example.edu/admission/index.html?year=2026
  • https – protocol/scheme
  • www.example.edu – domain/host
  • /admission/index.html – path and resource
  • ?year=2026 – query parameter

4. Domain Name

A domain name is a human-readable address used to access a website. DNS translates it into the corresponding IP address.

6. Working Principle of a Website

  1. User enters a URL in a browser.
  2. DNS finds the server's IP address.
  3. The browser sends an HTTP/HTTPS request.
  4. The web server processes the request.
  5. The server sends HTML, CSS, JavaScript and other resources.
  6. The browser renders the webpage for the user.
