WEB TECHNOLOGY ASSIGNMENT – 5 QUESTIONS
============================================

Folders:
1. Q1_World_Wide_Web_Fundamentals
   - HTML webpage covering Internet, networks, URL, domain, browsers/servers,
     website working principle and client-side/server-side scripting.
2. Q2_Student_Admission_Form
   - Responsive HTML5/CSS3 admission form.
   - Demonstrates form elements, multiple input types, image, video, audio,
     CSS selectors, box model and responsive UI.
   - The video uses an MDN sample URL, so internet access is needed for video playback.
3. Q3_Fashion_Store
   - Attractive fashion homepage using HTML5/CSS3.
   - Demonstrates backgrounds, borders, text effects, animation, grid columns,
     hover effects and UI design principles.
4. Q4_Student_Grade_Calculator
   - JavaScript grade calculator for five subjects.
   - Demonstrates variables/data types, literals, operators, selection,
     iteration (array methods) and a user-defined function.
5. Q5_Supermarket_Billing_System
   - JavaScript billing system for three products.
   - Calculates total, applies 10% discount when total exceeds ₹2000,
     and displays final payable amount.
   - Demonstrates variables/data types, literals, operators, statements and function.

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open any question folder.
3. Double-click index.html, or open it in Chrome/Edge/Firefox.
4. For Q4 and Q5, enter values and click the button.
5. For Q2, the local image/audio work offline. The sample video needs internet.
